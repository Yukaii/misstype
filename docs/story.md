## 深夜客運上的摸黑打字

這件事最早是在一次深夜的長途客運上發生的。

車廂熄了燈，四周都在睡覺。腦子裡突然冒出一堆想寫下來的靈感和雜記，但我根本不想打開頭頂那顆刺眼的閱讀燈，既會吵到旁邊的人，在黑暗裡亮著也特別累。

可是摸黑盲打手機或筆電？手只要稍微移位一公釐，敲出來的全是一堆亂碼。那時候就在想：如果兩手各拿一塊巴掌大的獨立小觸控板，放在大腿兩邊，完全不用看鍵盤，光靠肌肉記憶隨便敲敲就能打出字，該有多好？

---

## 做了原型，才發現事情沒那麼簡單

於是我開始動手做原型（最初的 M0–M2 階段，詳見 [docs/project-outline.md](project-outline.md)）。

但平滑的觸控板沒有實體鍵帽的物理邊界。敲擊只是連續的 `(x, y)` 座標：

- **按到隔壁鍵**：手指常落在按鍵邊界周圍（鄰鍵偏斜）。
- **順序打反**：兩隻手打快時，時間順序很容易顛倒（例如按快把「ㄐㄧㄣ」打成 `urp`）。
- **漏按符號**：滑太快漏敲某個音節符號。

這表示輸入法根本不能只做死板的精確字碼匹配，它得能吃下這些充滿不確定性的模糊輸入，並猜出整句話。

## Jev 模型與日本工程師的啟發

剛好那陣子 Typesafe AI 發表了 Jev 模型，專注於極速 token 選擇與約束候選排名。

我心想：這不就超適合拿來做輸入法的自動選字與候選重排嗎？

不久後，又看到社群上有位日本工程師用模型偵測上下文，做出了可以在同一個輸入流中自動混打日文和英文的輸入法，完全不需要手動按鍵切換。這讓我更確定了一件事：傳統輸入法那種「敲固定按鍵、跳選字框、手動翻頁選字」的 90 年代交互，早就該換個方式了。

## 為什麼不先做注音？

折騰硬體折騰到一半，突然一個念頭打醒我：

> 「我每天在電腦上打注音打得這麼痛苦，為什麼不乾脆先幫注音做一個好用的輸入法？」

現有的注音輸入法用起來真的常常讓人煩躁：

1. **強迫打聲調**：聲調鍵散落在最上方的數字列，每打一個字手指就要大幅往上拉扯。
2. **打錯一個鍵就完蛋**：打快時順序反了、按到隔壁鍵，整串直接壞掉，只能狂按退格鍵。
3. **思緒一直被打斷**：打兩三個字就要停下來看候選清單選字，原本想寫的事情都被切碎了。

那不如先做一個：**不用打聲調、順序打反能猜到、按到鄰鍵能救回、整句一口氣打完**的輸入法。

動手做了第一個版本，沒想到手感意外地順，隨打注音就正式啟程了。

## 用 Zig 重寫核心：追求極致速度與乾淨架構

最初的解碼原型先用 Python 和 Swift 寫。在 macOS 上還行，但當我想把輸入法搬到 Linux（fcitx5 / IBus）時，問題就來了：

- Swift 在 Linux 上的環境和 runtime 超級龐大，跨平台編譯痛苦萬分。
- 輸入法要求每次按鍵都必須在毫秒內反應，Swift 的 ARC 記憶體分配在頻繁搜尋晶格時開銷很大。

於是決定：**用 Zig 把整個輸入法核心徹底重寫（`core-zig/`）**。

換成 Zig 之後爽度大增：

- **單一工具鏈**：同一個編譯器，一鍵跨編譯 macOS、Linux（x86_64 / aarch64）跟 WebAssembly。
- **乾淨的 C ABI**：直接匯出 `misstype.h`，macOS 和 Linux 原生層直接 link，零膠水層包袱。
- **Arena 記憶體配置**：每次按鍵解碼所需的記憶體全由 arena 分配，解碼完瞬間 O(1) 一次釋放，完全沒有記憶體洩漏或碎片。
- **極致速度**：整句長句解碼只要 0.1ms 到 0.5ms，按鍵反應完全沒有任何遲鈍感。

詳細架構與 benchmark 紀錄見 [docs/zig-port.md](zig-port.md)。

## WebAssembly 與網頁編輯器：哪裡都能隨手打

核心用乾淨的 Zig 寫完後，順手把它編譯成了 WebAssembly（`wasm32-wasi`）。

這順便解決了一個大問題：在 iPad 上外接實體鍵盤時，系統根本不准你裝任何第三方輸入法。

但既然 WASM 可以在瀏覽器裡跑得飛快，那我何不直接寫一個內建隨打注音的 [Markdown 編輯器](https://misstype.yukai.dev/editor/)（詳見 [docs/editor.md](editor.md)）？

- **零安裝**：不用下載任何軟體、不用管管理者權限，在任何別人的電腦、公用機台或 iPad 上打開瀏覽器就能直接打。
- **支援離線**：做成 PWA，第一次打開後就快取到本地，沒網路也能順順寫。

## 寫在最後

回頭看，這整個專案就是從深夜客運上一個「不想開燈又想打字」的念頭開始，一路折騰原型、被模型啟發，最後轉向解決自己每天真實面對的注音痛點。

如果你也跟我一樣，打字時不想管聲調、手滑按錯也想被溫柔包容，歡迎載來玩玩看，或者直接在線上編輯器敲敲看！
