Misstype 隨打注音
Download GitHub 中文

Type Zhuyin. Skip the tones.

Wrong key, swapped keys, a missed key: usually you still get the sentence you meant.

Download for macOS Free · macOS 13+ · also on Linux

Like this

No tones anywhere. Mistakes in red.

  • No tones ㄐㄧㄣㄊㄧㄢㄊㄧㄢㄑㄧㄏㄣㄏㄠ → 今天天氣很好
  • Swapped ㄧㄐㄣㄊㄧㄢㄊㄧㄢㄑㄧㄏㄣㄏㄠ → 今天天氣很好
  • Missed one ㄇㄧㄥㄊㄧㄢㄗㄠㄕㄤㄐ‸ㄡㄉㄧㄢㄎㄞㄏㄨㄟ → 明天早上九點開會
  • Next key over ㄒㄧㄝㄒㄧㄝㄎㄧㄅㄤㄇㄤ → 謝謝你幫忙

If it guesses wrong, press ↓ and pick another character.

Also

  • Same keyboard layout as regular Zhuyin. Tones still work if you type them.
  • No internet needed. What you type stays on your computer.
  • Characters you pick come first next time.
  • Add your own words: select with Shift+←, press Return.
  • Tap Shift to switch between Chinese and English.
  • Updates itself.

Install

  1. Download the .dmg.

  2. Open it and double-click “Install Misstype”. No password needed.

  3. Log out and back in, then pick “Misstype Bopomofo” from the input menu.

    Not there? System Settings → Keyboard → Input Sources → +

Linux (fcitx5): see here.

One more thing

I made this for myself. It's new and it will have rough edges.

If you want a solid everyday Zhuyin input method, use vChewing. If you want to try typing this way, go ahead, and tell me what breaks on GitHub.

Standard Zhuyin layout only. No Cangjie, Pinyin or Simplified Chinese.

Open source, MIT. Dictionary from McBopomofo and libtabe.
