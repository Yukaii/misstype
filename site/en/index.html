Misstype 隨打注音
Download GitHub 中文

Type Zhuyin without tones.
Typos are fine.

Just keep typing. Misstype reads the whole phrase and puts the sentence together for you. Hit a neighboring key, swap two keys or miss one, and it still tries to work out what you meant.

It doesn't always guess right. When it doesn't, press ↓ to see the candidates and swap the wrong character. If you'd rather it stay strict, the repairs can be turned off in Settings.

Other things you might want to know

Nothing new to learn
It uses the standard Zhuyin keyboard layout. If you want to type tones you still can, and it respects them.
Offline, no data collected
Everything is worked out on your own computer and what you type never leaves it. The only network use is checking for updates. A remote-model helper exists in Settings, off by default; it is never used unless you turn it on.
Gets better as you use it
Characters you pick come up first next time.
Teach it new words
Names, shops, jargon: after typing, select the word with Shift+← and press Return. It remembers.
Switch to English
Tap Shift once to switch between Chinese and English.
Updates itself
New versions install quietly in the background. No reinstalling.

Install

macOS, about a minute.

  1. Download Misstype-<version>.dmg from the download page.

  2. Open it and double-click “Install Misstype”.

    It installs into your own user folder. No admin password needed.

  3. Log out and back in, then choose “Misstype Bopomofo” from the input menu in the menu bar.

    Not there? Add it in System Settings → Keyboard → Input Sources with “+”.

On Linux? It runs as an fcitx5 addon; see the Linux notes.

To be upfront

Misstype is new. I wrote it for myself and then shared it. The idea is lazy on purpose: skip the tones, don't aim too carefully, and let the computer work out the rest.

If you want a mature input method that just works every day, I recommend vChewing. It's great. If you have the same lazy itch, give this one a try and tell me what breaks on GitHub.

Only the standard Zhuyin layout is supported. No Cangjie, Pinyin or Simplified Chinese, and none are planned for now.

Misstype is open source under the MIT license. The bundled dictionary comes from McBopomofo (MIT) and libtabe (BSD-style).
