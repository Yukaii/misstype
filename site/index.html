一路打下去就好。隨打注音會看前後文，幫你把注音組成整句；按到隔壁的鍵、順序打反、漏打一個符號，它也會盡量猜回你要的字。

其他你可能想知道的

不用重學
用的是一般的注音鍵盤排列，會打注音就會用。要打聲調也可以，打了就照你打的。
不連網，不收集資料
選字全在你自己的電腦上算，打的字不會傳出去，只有檢查更新時會連網。設定裡有一個預設關閉的「遠端模型輔助」，你沒打開就不會用到。
越用越順手
你選過的字，下次會優先出現。
教它新的詞
人名、店名、專有名詞：打完後按 Shift+← 把詞框起來，按 Return 就記住了。
中英切換
輕按一下 Shift 就能切換中文和英文。
自動更新
有新版本時會自己在背景更新，不用重新安裝。

安裝

macOS，大約一分鐘。

  1. 到 下載頁面 下載 Misstype-版本.dmg。

  2. 打開下載的檔案，雙擊「Install Misstype」。

    會裝在你自己的帳號底下，不需要輸入管理者密碼。

  3. 登出再登入，然後在選單列的輸入法選單裡選「隨打注音」。

    找不到的話，到「系統設定 → 鍵盤 → 輸入方式」按「+」加入。

用 Linux？目前以 fcitx5 支援，安裝方式請看 Linux 說明。

先說清楚

隨打注音還很新，是我做給自己用、再分享出來的輸入法。出發點很懶：不想管聲調，手指也不想對得很準，打完讓電腦去猜。

如果你要的是成熟穩定、每天都不出錯的輸入法，我推薦 唯音（vChewing），它很好用。如果你也有一樣的懶人需求，歡迎試試看，遇到問題請到 GitHub 告訴我。

目前只有標準注音鍵盤排列，沒有倉頡、拼音或簡體中文，短期內也不打算做。

隨打注音（Misstype）以 MIT 授權開源。內建詞庫來自小麥注音（MIT）與 libtabe（BSD 風格授權）。
