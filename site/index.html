安裝方式

  1. 下載 .dmg 檔。

  2. 打開後，點兩下「Install Misstype」。不需要管理者密碼。

  3. 登出再登入，在選單列的輸入法裡選「隨打注音」。

    沒看到的話：系統設定 → 鍵盤 → 輸入方式 → 按「+」加入。

Linux（fcitx5）

從最新 Release下載對應套件：

sudo pacman -U ./Misstype-*-arch-*.pkg.tar.zst

Ubuntu 24.04：

sudo apt install ./Misstype-*-ubuntu24.04-*.deb

Fedora：

sudo dnf install ./Misstype-*-fedora*.rpm

若沒有適合的套件，才從原始碼安裝。Arch Linux／Omarchy 先安裝建置工具：

sudo pacman -S --needed base-devel cmake ninja git

Ubuntu 24.04 先安裝 Git：

sudo apt-get update && sudo apt-get install -y git

接著下載專案並進入目錄：

git clone https://github.com/Yukaii/misstype.git && cd misstype

Ubuntu 24.04 再準備其餘環境：

script/linux/bootstrap.sh

接著在專案根目錄執行：

script/linux/install_ime.sh

安裝完成後重新登入，開啟 fcitx5-configtool，加入「Misstype」輸入法，再用 fcitx5 的快捷鍵切換。

複製這段給 coding agent 代為安裝 
請在這台 Linux 電腦安裝 Misstype：
1. 先偵測發行版與架構；需要 sudo 時先告訴我並取得同意。
2. 優先從最新 Release 下載並安裝對應的 Arch、Ubuntu 24.04 或 Fedora 套件；若沒有相符套件，再 clone https://github.com/Yukaii/misstype.git。
3. 從原始碼安裝時，Arch／Omarchy 安裝 base-devel、cmake、ninja、git；Ubuntu 24.04 執行 script/linux/bootstrap.sh。
4. 從專案根目錄執行 script/linux/install_ime.sh。
5. 確認 fcitx5 正在執行，並用 fcitx5-configtool 將 Misstype 加入輸入法群組。
6. 重新啟動或重新登入後，用 fcitx5 的快捷鍵切換，輸入 su3cl3 確認預覽為「你好」。
若目前環境不符合支援條件，請說明原因並停止，不要刪除既有輸入法。

寫在前面

這是我為了滿足自己「不用對準鍵盤、不打聲調」的懶人打字需求做出來的輸入法，目前還很新，難免有些小毛病。

如果你想要的是成熟穩定、每天工作可靠的注音輸入法，真心推薦 唯音（vChewing）。如果你也有一樣的懶人打字渴望，歡迎下載試試看，遇到問題請到 GitHub 跟我說！

這個輸入法主要照我的個人打字習慣發展，目前專注在標準注音排列，沒有規劃加入其他輸入方式或簡體中文。
