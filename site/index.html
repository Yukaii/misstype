日常好用的細節

  • 標準注音鍵盤排列，想打聲調隨時可以打。
  • 純本機運算，不需網路，你打的字不會傳出去。
  • 越用越順手，選過的字詞下次自動排到最前面。
  • 自訂詞庫超直覺：按 Shift+← 選起來，按 Return 就記住了。（絕贊參考唯音）
  • 輕按一下 Shift 快速切換中英文。
  • 內建背景自動更新。
  • 作者每日使用，每日折騰改造。

安裝方式

  1. 下載 .dmg 檔。

  2. 打開後，點兩下「Install Misstype」。不需要管理者密碼。

  3. 登出再登入，在選單列的輸入法裡選「隨打注音」。

    沒看到的話：系統設定 → 鍵盤 → 輸入方式 → 按「+」加入。

Linux（fcitx5）請看這裡。

寫在前面

這是我為了滿足自己「不用對準鍵盤、不打聲調」的懶人打字需求做出來的輸入法，目前還很新，難免有些小毛病。

如果你想要的是成熟穩定、每天工作可靠的注音輸入法，真心推薦 唯音（vChewing）。如果你也有一樣的懶人打字渴望，歡迎下載試試看，遇到問題請到 GitHub 跟我說！

這個輸入法主要照我的個人打字習慣發展，目前專注在標準注音排列，沒有規劃加入其他輸入方式或簡體中文。
