隨打注音 Misstype
下載 GitHub English

打注音，不用管聲調。

按錯鍵、打反、漏打一個都沒關係，打完通常就是你要的那句。

下載 macOS 版 免費 · macOS 13 以上 · 也有 Linux 版

都沒打聲調，紅色是打錯的地方。

  • 沒打聲調 ㄐㄧㄣㄊㄧㄢㄊㄧㄢㄑㄧㄏㄣㄏㄠ → 今天天氣很好
  • 打反了 ㄧㄐㄣㄊㄧㄢㄊㄧㄢㄑㄧㄏㄣㄏㄠ → 今天天氣很好
  • 漏了一個 ㄇㄧㄥㄊㄧㄢㄗㄠㄕㄤㄐ‸ㄡㄉㄧㄢㄎㄞㄏㄨㄟ → 明天早上九點開會
  • 按到旁邊的鍵 ㄒㄧㄝㄒㄧㄝㄎㄧㄅㄤㄇㄤ → 謝謝你幫忙

猜錯的時候，按 ↓ 換一個字。

還有

  • 鍵盤排列跟一般注音一樣，想打聲調也可以。
  • 不用網路，打的字不會傳出去。
  • 你選過的字，下次會排前面。
  • 人名、店名可以自己加：Shift+← 選起來，按 Return。
  • 輕按 Shift 切換中英文。
  • 會自己更新。

安裝

  1. 下載 .dmg 檔。

  2. 打開，點兩下「Install Misstype」。不用輸入密碼。

  3. 登出再登入，在選單列的輸入法裡選「隨打注音」。

    沒看到的話：系統設定 → 鍵盤 → 輸入方式 → +

Linux（fcitx5）請看這裡。

先說一下

這是我做給自己用的輸入法，還很新，難免有問題。

想要穩定好用的注音輸入法，推薦唯音。想試試這種打法的，歡迎下載，有問題到 GitHub 跟我說。
